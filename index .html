AI setup

Connect an AI provider (Gemini, OpenAI, Anthropic, OpenRouter, Groq, Ollama or any OpenAI-compatible server) so the vault can rewrite pasted questions, write solutions and test cases, run languages the browser cannot, and mark your answers.

Tip: if you already have a subscription to an AI tool (OpenAI, Claude, Gemini and others), choose that provider here and use its API key for the smoothest experience. API access is billed separately from the chat app, so create the key on the provider's developer page.
Each provider keeps its own key and model, so you can switch whenever you like.

Code runner

Java, C++, C, C#, Go, Rust, Kotlin, PHP, Ruby and other languages run for real on an online compiler, so the terminal shows exactly what the program prints. Python and JavaScript run inside your browser. This part needs no AI key.

The free public Judge0 server is used by default (Wandbox is the backup). If you host your own Judge0, put its address here.
Sent as X-Auth-Token to the address above. Only needed for a private Judge0 server.

How code runs here

  • JavaScript runs for real in your browser. Read input with require('fs').readFileSync(0,'utf8') or require('readline').
  • Python runs for real too, using Pyodide loaded from a CDN the first time (a few seconds, needs internet). If it cannot load, it runs on the online compiler instead.
  • Java, C++, C and other compiled languages cannot run inside a browser, so they are compiled and run on an online server and the real output comes back. This needs an internet connection and may take a second or two. Pages opened inside Claude cannot reach that server, so use your own site.
  • Never paste your key into the page code or push it to GitHub. Your pasted questions are sent to the provider you choose, and some free tiers may use them to improve their products, so avoid private material.
